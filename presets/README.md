# 搜索预设 / Search presets

预设 = 一份现成的 `config/search.yaml`：方向、标题族、关键词轮换、公司分层、校招站点、ATS 看板、黑名单。

| 预设 | 适合 |
|---|---|
| `uk-london-tech.yaml` | 在伦敦找科技类应届/初级岗位（软件/AI、电信、电子、自动驾驶/视觉、芯片设计） |

使用：设置时 Claude 会问你选哪个预设，然后删掉你不要的方向、把 `cv` 改成你的简历 id、补上你的时区和邮箱。
没有合适的预设：从 `config/search.template.yaml` 开始，Claude 会根据你的方向和城市帮你填。

欢迎贡献其他城市/行业的预设（只放公司和站点名单，不要放任何个人信息或投递记录）。
