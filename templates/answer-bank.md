# 常见开放题怎么答 / Common open questions

Claude 根据 `answer_bank` 和 JD 改写；**只用真实素材**。字数按表单限制。

| 题目 | 思路 | 素材来源 |
|---|---|---|
| Tell us about yourself | 现在在做什么 → 最相关的 1–2 个经历 → 为什么申请这个岗位 | elevator_pitch, projects |
| Why this company / role? | 2–3 个具体点：产品/技术/团队/项目设置，与自己经历的连接 | JD + 公司官网 |
| Describe a challenge | STAR，结果最好有数字 | answer_bank.stories |
| Teamwork | 自己负责的部分 + 如何协作 + 结果 | stories, team projects |
| Strengths / weaknesses | 优势配证据；待提升项配已在做的改进 | strengths, development_area |
| Salary expectation | profile.job_search.salary_expectation；岗位已给区间时可写“within the advertised range” | profile |
| Anything else? | 可写补充信息（作品集、可入职时间），不要重复简历 | — |

JD 或申请表声明禁止 AI 作答时：只放 `[DRAFT - 请自己改写]` 标记，不写 AI 生成的正文，由本人自己写。
