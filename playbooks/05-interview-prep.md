# 05 · 测评与面试准备 / Assessments & interviews

1. 用编号在 `data/JD_archive.md` 里搜索 `## #<编号>` 找到 JD（不要整份读）。
2. 明确形式：在线测评（数字/逻辑/性格/编程）、视频面试、技术面、行为面、终面。
3. 准备内容：
   - 技术面：根据 JD 技术栈列出高频知识点 + 用户项目里可能被追问的细节（只基于 profile 里的项目）。
   - 行为面：把 `answer_bank.stories` 对应到该公司价值观/JD 要求；缺故事就问用户要真实经历。
   - 为什么选我们公司：结合 JD 和公司公开信息，写 3 个要点让用户自己组织语言。
   - 编程测评：给练习方向和时间安排，不代做测评。
4. 产出 `data/interview_prep/<编号>_<公司>.md`。
5. **不代替用户参加或完成任何测评/面试。**
